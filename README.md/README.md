# Python Activity-Based Learning (ABL)

## About the Project
This repository contains 10 Python case study projects developed as part of the Python Programming Activity-Based Learning (ABL). Each project solves a real-world problem using basic Python programming concepts.

## Objectives
- Develop computational thinking and problem-solving skills.
- Understand algorithms and pseudocode.
- Practice conditional statements and loops.
- Work with strings, lists, nested lists, and tuples.
- Apply Python concepts to practical scenarios.
- Improve programming skills through hands-on activities.

## Technologies Used
- Python 3
- Visual Studio Code
- GitHub

## How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the required experiment folder.
4. Open the Python file.
5. Run the program using:

```bash
python filename.py
```

Replace `filename.py` with the corresponding Python source file name.
